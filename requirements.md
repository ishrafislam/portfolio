# Portfolio Website — Development Requirements

## 1. Project Overview

Build a modern, professional, highly polished personal portfolio website for **Md. Ishraf Islam**, a Senior Software QA Engineer based in Dhaka, Bangladesh.

The website should position Ishraf as a **Quality Engineer / Software QA Engineer who specializes in test automation, API testing, mobile testing, performance testing, complex SaaS systems, and quality engineering**.

The website must feel like the portfolio of an experienced software engineer—not a generic resume website.

The primary objective is to communicate:

- Professional experience
- QA and automation expertise
- Complex products worked on
- Technical breadth
- Engineering mindset
- Leadership and collaboration
- Personal software projects
- Ability to work with modern technologies

Do **not** simply reproduce the resume. Convert the information into a compelling engineering portfolio.
